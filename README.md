> Extracts 77 features from binary headers, sections, and imports — classifies as **malware** or **benign** in milliseconds, without executing the file.

## 🔬 Feature Engineering (77 features)

We extract **77 features** across 5 categories from the PE (Portable Executable) binary format:

| Category | Count | Key Signals |
|---|---|---|
| **Header** | 22 | `compile_timestamp` (0 in malware), `checksum`, `entry_point_entropy` |
| **Sections** | 14 | Shannon entropy, `virtual/raw ratio`, W^X sections, packer names |
| **Imports** | 21 | `CreateRemoteThread`, `WriteProcessMemory`, `IsDebuggerPresent`, network DLLs |
| **Strings** | 10 | URLs, IP addresses, base64 blobs, registry keys, `powershell`/`cmd.exe` |
| **Metadata** | 7 | `file_entropy`, `has_debug_info`, packing heuristic |

### Why entropy is the key signal

Shannon entropy measures randomness in byte sequences. Malware authors encrypt or compress their payloads to evade signature detection — this spikes entropy above 7.0. Legitimate executables sit between 4.0–6.5.

## 📦 Using with Real Data

This project is compatible with the **[EMBER dataset](https://github.com/elastic/ember)** (Elastic Malware Benchmark for Empowering Researchers — 1.1M PE files).

To extract features from your own PE samples:

```bash
# Extract features from a directory of malware
python src/feature_extractor.py -d /path/to/malware/ -l 1 -o malware_features.csv

# Extract features from benign samples  
python src/feature_extractor.py -d /path/to/benign/ -l 0 -o benign_features.csv

# Combine and train
cat malware_features.csv benign_features.csv > combined.csv
python src/train.py --data combined.csv
```
